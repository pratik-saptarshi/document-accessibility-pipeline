# Document Accessibility Pipeline

Open-source planning workspace for accessible document generation and existing-PDF accessibility remediation. The project is in its planning stage; no production architecture or implementation has been approved.

Start with the [documentation index](docs/README.md), [product scope](docs/requirements/product-scope.md), and [test-driven product roadmap](docs/roadmap/product-roadmap.md).

Both lanes address statements, invoices, correspondence, and reports. The remediation lane focuses on existing PDFs and an open-source toolchain. The generation lane is broader: data and templates, DOCX and Markdown sources, and PDF output. IBM AFP print migration is a separate feasibility track.

See [contribution conventions](CONTRIBUTING.md) for Git and Beads issue tracking guidance. Proposed decisions and feasibility candidates must be labeled as such until evidence is reviewed.
