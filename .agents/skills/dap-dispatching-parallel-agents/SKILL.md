# Parallel work

Delegate only independent, bounded subtasks that contribute to the requested
outcome. Assign one owner and a concrete deliverable to each, give the minimum
necessary context, and state shared-file boundaries. Do not delegate actions
that require authorization the user has not granted. Do not duplicate repository
work or ask multiple agents for the same review unless independent opinions are
the point of the request.

Integrate sequentially: inspect every result, check changed files and evidence,
resolve conflicts, and verify the assembled work under current repository
rules. Agent reports are not proof by themselves. Preserve pre-existing changes
and stop if a result's scope or safety is uncertain.
