# Requirements

Requirements are being refined. The [product scope](product-scope.md) captures current boundaries and unresolved choices. PDF/UA-2 is the accepted output target in [Decision 0001](../decisions/0001-pdf-ua-2-validation-target.md), and the approver persona/protocol is accepted in [Decision 0004](../decisions/0004-approver-persona-review-protocol.md). Semantic policy, authoritative role verification, and release-evidence implementation remain open.

The [profile contract](../profiles/README.md) records proposed data, accessibility, privacy, retention, and human-review fields separately for generation and remediation.

Use synthetic or deidentified cases for requirements, fixture plans, and examples. Include statements, invoices, correspondence, and reports in both product lanes.
